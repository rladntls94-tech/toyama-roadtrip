# 간사이 4박 5일 · 나라와 기이반도 자동차 여행 (2026.8.7–8.11)

🔗 **https://rladntls94-tech.github.io/toyama-roadtrip/**

간사이 국제공항에서 렌트카로 출발해 나라에서 기이반도 남쪽으로 내려갔다가
해안을 따라 돌아오는 자동차 여행 일정표입니다.
`index.html` 한 파일로 끝나는 self-contained 문서라 빌드도 의존성도 없습니다.

## 루트

```
8/7  (금)  간사이공항 19:00 → 나라 65km · 오코노미야끼          [나라 호텔 2박]
8/8  (토)  나라공원 사슴(아침) → 우동 → 당고쇼 → 호류지 → 이코마산조 야간
8/9  (일)  와카쿠사야마 · 이온몰 · 오코노미야끼 → (도쓰카와 휴게)
           → 구마노혼구타이샤 · 오유노하라 → 와타라세 대노천탕     [가쓰우라 1박]
8/10 (월)  나치폭포(아침) → 가쓰우라 참치 → 유노미네 쓰보유 → 시라하마 [바다 1박]
8/11 (화)  산단베키 · 센조지키 → 린쿠 아울렛·이온몰 → KIX 15:00 반납 (18:55 출발)
```

**총 주행 약 785km · 숙소 3곳**

## 설계 기준

- **오사카 시내 제외** — 도톤보리·신세카이·USJ 없음
- **시내 말고 풍경 위주** — 나라공원은 아침 6시 반, 나치폭포는 오전
- 필수 항목: 나라 사슴 / 이코마산조 유원지 야간 / 당고 / 오코노미야끼
- **온천** — **와타라세 대노천탕**(서일본 최대급, 21:30 마감) + **유노미네 쓰보유**(세계유산 등재 유일)

## 8/9 변경 — 忘帰洞 → わたらせ温泉

당일치기 입욕 **접수가 18:00에 끊기는** 忘帰洞 때문에 8/9 전체가 그 시각 하나에 묶여 있었습니다.
**21:30 마감(폐관 22:00)·연중무휴**인 와타라세 온천으로 바꾸면서 그 압박이 사라졌습니다.

| | 忘帰洞 | わたらせ温泉 |
|---|---|---|
| 마감 | 당일입욕 **18:00** | **21:30** (폐관 22:00) · 연중무휴 |
| 요금 | ¥2,500 | 약 ¥1,000 |
| 위치 | 가쓰우라 — 도착 후 배로 재이동 | 혼구 — **지나가는 길** |
| 규모 | 동굴 노천탕 | **서일본 최대급** 노천탕 |

함께 바뀐 것 세 가지:

1. **헤이조궁터 제외** — 주작문 하나 있는 빈 벌판이라 잘라낼 것 중 손실이 가장 적습니다. **1시간 확보**
2. **大斎原(오유노하라)를 8/10 13:30 → 8/9 16:50으로 이동** — 정오 빛이 이 장소에서 가장 나쁘고,
   어차피 혼구를 지나갑니다. 덕분에 **8/10이 크게 여유로워짐**(나치 → 참치 → 쓰보유 → 시라하마)
3. **8/9 참치 저녁 포기** — 19:40 도착이라 무로마루(19시 마감)를 못 맞춥니다.
   참치는 **8/10 11:00 점심**에 이미 잡혀 있으니 8/9 저녁은 가쓰우라 시내 이자카야로

## 8/9 도츠카와 구간 정리 — 谷瀬 · 果無 제외

**谷瀬の吊り橋(구글 3,000+)와 果無集落을 뺐습니다.** 문제는 대체지가 없다는 점입니다 —
고조~혼구 **115km 산길에서 구글 리뷰 500건을 넘는 곳은 玉置神社 하나**인데,
도쓰카와온천에서 **편도 12km 산길 50분 + 도보 15분**이라 왕복 2시간 40분이라 들어가지 않습니다.
**瀞峡 제트보트**도 후보였으나 **2025년 4월 10일자로 운행 폐지**됐습니다.

그래서 중간을 억지로 채우지 않고, **혼구에 도착해서 시간을 쓰는 쪽**으로 바꿨습니다.

| 시각 | 대체 후 | 비고 |
|---|---|---|
| 14:40 | **道の駅 十津川郷** (휴게 20분) | 관광지 아님 — 무료 족욕(24시간)·화장실. 2시간 연속 운전 뒤 필수 |
| 15:55 | **熊野本宮大社** (45분) | 구마노 산잔 총본궁·세계유산. **구글 리뷰 수천 건** |
| 16:50 | 大斎原 대도리이 (25분) | **같은 주차장에서 도보 10분** — 추가 운전 0km |

혼구타이샤는 원래 "본전 참배는 건너뛴다"고 적혀 있던 곳인데, 빈 시간이 정확히 그 자리에 생겼습니다.
158단 돌계단 위 **檜皮葺(편백 껍질 지붕) 사전 4채**가 주홍색을 칠하지 않은 검은 나무 건물이라,
8/8 가스가타이샤·8/10 나치의 주홍색과 대비가 큽니다. 야타가라스 우체통도 여기 있습니다.

> ⚠️ 국도 168호 도츠카와 구간은 **공사·낙석 통행규제가 잦고 대체 도로가 없습니다.**
> 출발 아침에 도로정보를 한 번 확인하세요.

### 조정 레버

- **谷瀬 또는 果無를 되살리려면** 둘 중 **하나만** 넣으세요 — 각각 40분+이동이라
  둘 다 넣으면 혼구타이샤를 포기해야 합니다. 果無는 임도 왕복 20분 + 주차 4대뿐
- **더 당기고 싶으면** 혼구타이샤 참배(45분)를 大斎原만 보는 것으로 줄이세요
  → 가쓰우라 **19:00 도착**, 무로마루 참치 저녁도 가능
- **진짜 노을을 원하면** 와타라세를 먼저(16:45) 하고 도리이를 18:15에 —
  **일몰 18:50**이라 골든아워 정면이고, 가쓰우라 도착 시각은 19:45로 거의 같습니다
- **온천을 더 싸게** → 湯泉地温泉 滝の湯 (도츠카와무라, R168 옆, ¥400, 8:30~20:00, 목요일 휴무 —
  8/9은 일요일이라 영업). 다만 大斎原보다 북쪽이라 순서가 바뀝니다
- **ホテル昴 星の湯는 비추천** — 당일입욕 12:00~17:00이라 忘帰洞과 똑같은 시간 문제가 반복됩니다
- **忘帰洞이 정말 아깝다면** 가쓰우라 숙소를 **호텔 우라시마 자체**로. 숙박객은 밤·아침에 여유롭게
  쓸 수 있어 18시 컷오프가 무의미해집니다 (「숙소」 탭에 대안 카드로 넣어뒀습니다)

## 기능

- **실제 지도** — Leaflet + CARTO 타일. 날짜별 경로 on/off, 마커 클릭 시 시각·메모
- **후보지 카드 사진** — 「더 갈 곳」 탭을 열면 일본어 위키백과 REST API에서 썸네일을 가져와 카드에 깔아줍니다.
  IntersectionObserver로 화면에 들어온 카드만, 200ms 간격 큐로 요청합니다(위키백과 429 회피).
  항목에 사진이 없으면 이모지 플레이스홀더가 그대로 남습니다
- **마우스오버 미리보기** — 장소 링크에 마우스를 올리면 위키백과 사진을 카드로 표시
- **탭 딥링크** — `#food`, `#view`, `#more`, `#hotel`, `#play`, `#prep`
- **다크모드** — `prefers-color-scheme` 대응
