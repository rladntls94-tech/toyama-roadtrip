# 간사이공항 ↔ 북알프스 4박 5일 자동차 여행 (2026.8.7–8.11)

🔗 **https://rladntls94-tech.github.io/toyama-roadtrip/**

간사이 국제공항에서 렌트카로 출발해 일본 북알프스를 종단하고 돌아오는 자동차 여행 일정표입니다.
`index.html` 한 파일로 끝나는 self-contained 문서라 빌드도 의존성도 없습니다.

## 루트

```
8/7  (금)  간사이공항 19:00 출발 → 도야마 460km 야간 종주        [도야마 2박]
8/8  (토)  고카야마 아이노쿠라·스가누마 → 시라카와고 → 이와세
8/9  (일)  다테야마 무로도 2,450m → 다카야마 저녁 → 히라유온천    [히라유 1박]
8/10 (월)  가미코치(다이쇼이케·갓파바시·묘진이케) → 다카야마 → 게로온천  [게로 1박]
8/11 (화)  게로온천 10:00 출발 → 간사이공항 13:20 (18:55 출발편)
```

**총 주행 약 1,270km · 통행료 약 ¥22,000 · 숙소 3곳**

| ✅ 준비 | 예약 체크리스트, 야간운전 대비, 고산 복장, 날씨 리스크 |

## 이 일정의 설계 원칙

**고산 두 곳은 자가용이 못 들어갑니다.** 무로도는 다테야마역(무료주차 900대)에서 케이블카+고원버스로
60분, 가미코치는 아칸다나 주차장(¥600/일)에서 셔틀버스 30분. 이 환승 시간이 일정의 골격을 정합니다.

**8/9 밤에 히라유까지 가둬두는 게 핵심 수(手)입니다.** 가미코치 셔틀은 히라유에서 30분이면 닿는데,
도야마에서 출발하면 이동만 2시간 45분이라 가미코치 아침이 통째로 날아갑니다.

**고산은 전부 오전 승부.** 오후엔 구름이 끼고 소나기·뇌우가 잦습니다.

## 기능

- **실제 지도** — Leaflet + CARTO 타일. 날짜별 경로 on/off, 마커 클릭 시 시각·메모. 오프라인이면 위경도 개략도로 대체
- **마우스오버 미리보기** — 장소 링크에 마우스를 올리면 위키백과에서 사진과 설명을 실시간으로 가져와 카드로 표시
- **구글맵 길찾기** — 경유지까지 미리 넣은 날짜별 링크
- **다크모드** — `prefers-color-scheme` 대응
- **탭 딥링크** — `#food`, `#udon`, `#hotel`, `#prep`
