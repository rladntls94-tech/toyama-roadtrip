# 간사이 4박 5일 · 나라와 기이반도 자동차 여행 (2026.8.7–8.11)

🔗 **https://rladntls94-tech.github.io/toyama-roadtrip/**

간사이 국제공항에서 렌트카로 출발해 나라에서 기이반도 남쪽으로 내려갔다가
해안을 따라 돌아오는 자동차 여행 일정표입니다.
`index.html` 한 파일로 끝나는 self-contained 문서라 빌드도 의존성도 없습니다.

## 루트

```
8/7  (금)  간사이공항 19:00 → 나라 65km · 오코노미야끼          [나라 호텔 2박]
8/8  (토)  나라공원 사슴(아침) → 우동 → 당고쇼 → 호류지 → 이코마산조 야간
8/9  (일)  와카쿠사야마 · 헤이조궁터 · 오코노미야끼 → 다니세 현수교 → 도츠카와 온천  [산속 1박]
8/10 (월)  유노미네 쓰보유 → 오유노하라 → 나치폭포 → 시라하마       [바다 1박]
8/11 (화)  산단베키 · 센조지키 → 린쿠 아울렛·이온몰 → KIX 15:00 반납 (18:55 출발)
```

**총 주행 약 610km · 숙소 3곳 (호텔 2박 + 에어비앤비 2박)**

## 설계 기준

- **오사카 시내 제외** — 도톤보리·신세카이·USJ 없음
- **사람 적고 풍경 위주** — 나라공원은 아침 6시 반, 미타라이 계곡은 9시 전 도착
- 필수 항목: 나라 사슴 / 이코마산조 유원지 야간 / 당고 / 오코노미야끼
- 온천 최소 하나 — 도츠카와(원천 100% 가케나가시) + 유노미네 쓰보유(세계유산)

## 구성

| 탭 | 내용 |
|---|---|
| 🗺 루트 & 일정 | Leaflet 지도(날짜별 경로 토글·마커 팝업) + 5일치 타임라인 + 구간 요약 |
| 🍽 당고 & 오코노미야끼 | 당고쇼·니시나 고키안, 나라 오코노미야끼 7곳 평점표와 영업시간 |
| 🏞 풍경 스팟 | 일정에 든 6곳 + 기타 후보(소니 고원·오다이가하라·코야산·하시구이이와) |
| 🏨 숙소 | 나라 호텔 2곳, 에어비앤비 후보, 산속·바다 숙소 찾는 법과 조합별 예산 |
| 🎢 이코마 & 놀거리 | 유원지 영업정보, 게임센터·가챠, 쇼핑 |

## 확인이 필요한 항목

- **이코마산조 유원지 8/8(토) 야간영업** — 8월 *평일* 12:00~21:00은 공식 확인됐으나
  주말 시간표는 이미지 캘린더라 미확인. ☎ 0743-74-2173
- **미타라이 계곡 주차** — 대수가 적어 여름 주말 10시면 만차. 8/9은 일요일
- **8/9 산속 · 8/10 바다 숙소** — 총량이 적어 나라 호텔보다 먼저 잡아야 함
- **8/9 저녁** — 도츠카와·유노미네는 밤에 문 연 식당이 사실상 없음 → 저녁 주는 숙소로

## 기능

- **실제 지도** — Leaflet + CARTO 타일. 날짜별 경로 on/off, 마커 클릭 시 시각·메모
- **마우스오버 미리보기** — 장소 링크에 마우스를 올리면 위키백과 사진을 카드로 표시
- **탭 딥링크** — `#food`, `#view`, `#hotel`, `#play`, `#prep`
- **다크모드** — `prefers-color-scheme` 대응
